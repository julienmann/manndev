Add / update a client

The client signs in with this username and password. Passwords aren't stored anywhere (only a login file derived from them is), so copy the password before saving: there's no way to look it up later.

Deploy

After editing clients, push the folder to the server (never committed to git). The script refuses to push if a client changed their password since your last pull, so you can't undo their change by accident.

./scripts/clients.sh push
