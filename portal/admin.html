Deploy

After adding clients, push the folder to the server (never committed to git). A cron job on the server fixes permissions automatically every 5 minutes, so you don't need a --chmod flag here (macOS's built-in rsync doesn't support it anyway):

rsync -av client-files/ lmann@lionelmann.com:/srv/www/manndev/client-files/
